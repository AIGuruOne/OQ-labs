# Day 2 fine-tuning stack (notebooks 05 and 06). Fully pinned, no ranges.

# THE DESIGN DECISION (2026-09-20, see docs/finetune_stack.md):
# plain transformers + peft + bitsandbytes. NOT unsloth.
#
#   Every package below except bitsandbytes is ALREADY on Colab at
#   exactly this version (source: github.com/googlecolab/backend-info,
#   pip-freeze.gpu.txt, checked 2026-09-20). So on a cold Colab runtime
#   notebook 05 installs ONE 43 MB wheel, downgrades nothing, and never
#   asks for a runtime restart.
#
#   unsloth 2026.9.7 (latest on PyPI, 2026-09-18) would be roughly 2x
#   faster, but its wheel metadata caps transformers<=5.5.0, trl<=0.24.0
#   and datasets<4.4.0. Colab ships transformers 5.16.1 and datasets
#   4.8.5, so installing it means downgrading the core of a cold
#   runtime in front of the room, then restarting it. It also cannot
#   run without a GPU, so its code path could not be tested off a T4.
#
# On Colab: do NOT install this file. Notebook 05's install cell
# installs bitsandbytes only.
# Locally (CPU smoke test, or the facilitator's fallback machine):
#     pip install torch==2.11.0 --index-url https://download.pytorch.org/whl/cpu
#     pip install -r requirements.txt -r requirements-finetune.txt
# Local Python 3.11 or 3.12 only (see CLAUDE.md).
#
# No compiled dependencies: every package here ships prebuilt wheels
# for Linux x86_64, Windows x86_64 and macOS arm64.
